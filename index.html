🚀 AVIONICS SYSTEM

1. System Overview

Sensors → Arduino Nano → Decision Logic → Actuators
Telemetry → LoRa → Ground Station
Backup → SD Card Logging

4. Wiring Summary

✔ Common Ground for all components ✔ 5V → Nano, GPS, SD, Servos ✔ 3.3V → Sensors, LoRa ✔ SPI shared (LoRa + SD with separate CS)

5. Communication

Sensors → Nano → LoRa → Ground Station ↓ SD Card (backup)

6. Flight Logic (State Machine)

0 BOOT 1 TEST_MODE 2 LAUNCH_PAD 3 ASCENT 4 PAYLOAD_SEPARATION 5 DESCENT 6 RECOVERY 7 IMPACT

7. Flowchart

START ↓ BOOT → TEST → WAIT ↓ LAUNCH DETECTED ↓ ASCENT ↓ APOGEE ↓ DEPLOY ↓ DESCENT ↓ RECOVERY ↓ IMPACT ↓ END

8. Working

The avionics system reads sensor data, processes it using Arduino Nano, and transmits telemetry via LoRa. At apogee, the system triggers servo-based payload separation and parachute deployment while storing backup data on SD card.
