🚀 AVIONICS SYSTEM – ROCKET & CAN-SAT

📘 Methodology

The system is divided into two independent subsystems: Rocket Avionics and CAN-SAT Avionics. The rocket handles flight control, apogee detection, and deployment, while the CAN-SAT operates independently after separation, collecting and transmitting environmental and positional data.

🧩 System Architecture

🚀 Rocket Avionics

  • Teensy 4.1 Microcontroller
  • BNO055 IMU
  • BMP388 Altimeter
  • LoRa (Channel 1)
  • Servo Deployment
  • SD Card Logging

🛰️ CAN-SAT Avionics

  • Teensy 4.1 Microcontroller
  • BNO055 IMU
  • BMP388 Sensor
  • GPS Module
  • Camera System
  • LoRa (Channel 2)

⚙️ Working Principle

During launch, the rocket avionics continuously monitors altitude and motion. At apogee, the system triggers a servo mechanism to eject the CAN-SAT. After separation, both systems operate independently and transmit telemetry data to the ground station using separate communication channels.

🧠 Flight Logic

BOOT → Sensor Initialization → Waiting for Launch → Launch Detected → Ascending Phase → Apogee Detection → CAN-SAT Deployment → Parachute Deployment → Descent → Landing

⚠️ Important Notes

  • All systems must share a common ground
  • Use regulated 5V power supply
  • Separate communication channels for Rocket and CAN-SAT
  • Ensure shock resistance (~30g)
  • Battery must sustain full mission duration
