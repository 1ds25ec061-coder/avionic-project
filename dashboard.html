🚀 IN-SPACe AVIONICS SYSTEM (ROCKET + CAN-SAT)

🚀 ROCKET AVIONICS SYSTEM

Project Methodology

  • Launch detection using IMU
  • Continuous altitude monitoring using MS5607
  • Apogee detection using pressure drop
  • CAN-SAT ejection using servo
  • Parachute deployment
  • Real-time telemetry transmission
  • Data logging on SD card

System Structure

  • Teensy 4.1 (Controller)
  • BNO055 (Orientation)
  • MS5607 (Barometer)
  • LoRa SX1278 (Communication)
  • MG90S Servo (Deployment)
  • SD Card Module
  • 18650 Battery + Boost Converter

Working Principle

  • System initializes sensors
  • Launch detected via acceleration
  • Altitude increases → ascent phase
  • Peak altitude → apogee detected
  • Servo triggers CAN-SAT ejection
  • Parachute deploys
  • Telemetry sent to ground

Flow Logic

START → Initialize System → Launch Detected? → YES → Monitor Altitude → Apogee Detected? → YES → Eject CAN-SAT → Deploy Parachute → Transmit Data → END

🛰️ CAN-SAT AVIONICS SYSTEM

Project Methodology

  • Independent operation after separation
  • Measure altitude and orientation
  • Track location using GPS
  • Capture video using onboard camera
  • Transmit telemetry data
  • Store data on SD card
  • Safe descent using parachute

System Structure

  • Teensy 4.1
  • BNO055 IMU
  • MS5611 (Barometer)
  • NEO-M8N GPS
  • LoRa SX1278 (Channel 2)
  • RunCam Nano Camera
  • SD Card Module
  • 18650 Battery

Working Principle

  • System active before launch
  • Remains passive during ascent
  • Separates at apogee
  • Activates full operation
  • Records sensor data and video
  • Transmits telemetry
  • Descends safely

Flow Logic

START → Initialize System → Wait for Separation → Activate Sensors + Camera → Collect Data → Transmit Telemetry → Land Safely → END
